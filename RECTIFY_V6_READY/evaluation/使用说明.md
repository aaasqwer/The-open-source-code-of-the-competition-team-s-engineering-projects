# 赛题二测评工具：使用说明

这套独立工具放在 evaluation，不修改原上位机程序、画面、拍照和串口枚举。
直接双击工程根目录“启动独立测评工具.bat”即可，不需要单独安装Python。也可使用下面的命令行入口；命令行方式需要Python及requirements.txt中的依赖。

example_manifest.json包含可直接运行的旧版720P效果图和明确标记的合成斜边。它们只演示工具，不是本工程相机验收照片。

## 1. 硬件帧率及端到端延迟

下载本目录所属工程的 V6 位流，保持摄像头正常显示。先在原上位机点击参数串口“关闭”，让出 COM 端口；图像网络界面不用改。
运行：

    python capture_performance.py --port COM6 --seconds 60 --output hardware_performance.json

COM6 改成当前板卡的参数串口。工具只发送新查询命令 A5 5A 60 00 5F，不切换模式、不写摄像头参数；读取并校验类型86的68字节数据和SUM8。测完关闭本工具，再在原上位机打开串口。

分别在原图、二阶模型、增强矫正、开启 IMU 和有效四角设置后按住 K0 平面正视时采集。每种状态至少60秒，记录同一位流哈希、图像分辨率及动作范围。

- sensor_vs_per_second：传感器帧同步次数，不等于完整捕获帧率。
- accepted_source_fps：完整捕获且提交的原始帧率。
- render_publications_per_second：处理完成次数，包括控制变化对同一原始帧的再次处理。
- unique_valid_display_fps：真正显示完成、没有欠读/尺寸错误的不同源帧数量，这是展示实时处理能力的主要帧率。
- hdmi_scan_fps：屏幕扫描帧率。重复显示不会当作新处理帧。
- source_first_pixel_to_hdmi_first_pixel_ms：从该帧第一个数字RGB565输入像素，到矫正画面第一个有效HDMI像素的延迟。输出引脚还有一级寄存器，另加13.468ns。镜头曝光和显示器响应不在其中。若需要光到光延迟，还要用闪烁LED和高速相机/光电探头另测。
- min/max：运行以来有效新源帧的最小/最大延迟；重置板卡可清零。
- invalid_display_frames：有源身份但欠读或尺寸错误的显示帧数，启动尚无图像的扫描不计入。
- capture_overflow_flag_rises：原捕获器溢出粘滞标志的上升次数，不能冒充丢帧总数。

源时间戳随原始帧描述符、处理帧和所选显示缓存一起传递；不能用当前最新相机帧的时间代替正在显示的帧。32位125MHz计时器每34.36秒回绕；正常连续工作时以模差统计远短于17秒的帧延迟，重复帧不更新延迟。测试期间应保持持续输入并避免长时间冻结。
两个时钟域通过注册的Gray时间和两级同步采样，FDC另外约束Gray各位偏斜小于7.5ns。采样误差为数个相机/像素时钟周期，不能把结果宣传为单时钟绝对精度。原始tick也保留在512位性能探针中，可用PDS ILA交叉检查。

## 2. 直线度

复制 example_manifest.json，填入实际PNG路径、分辨率一致的评估角色和每条物理直边的锚点。锚点允许沿弯曲边缘布置，工具最后始终拟合一条直线，保留检测到的全部有效采样点。不要把圆角、纸边翘曲、阴影边界、手指遮挡当作物理直线。
运行：

    python image_quality.py --manifest my_manifest.json --output quality_result.json

输出每条线的像素RMS、最大偏差、检测覆盖率、带红点的原图以及带符号的残差。任何分段检测覆盖率不足80%会标为无效，不能靠删除不直的点降低RMS。不同分辨率、不同裁剪/放大不能直接比较像素RMS。

## 3. MTF50 / SFR

需要清楚、平整、没有反光的黑色斜边/网格测试卡。以局部偏离水平/竖直约2至8度的单条斜边为ROI，避免饱和，ROI至少32×32，建议80×160以上。分别测中央、上下左右和四角，保持相机/板卡/卡片位置不变；原图与矫正图采用同分辨率，并记录变换尺度。
manifest中的 sfr_rois 用像素位置框选单条斜边，gamma必须注明：srgb、linear或已测得的解码指数。未知相机OECF时sRGB只是明确记录的近似，不是已测得的相机响应。
工具做4倍ESF采样、LSF求导、Hann窗、导数修正和FFT，给出MTF50（cycles/pixel）及完整SFR。弯曲/噪声过强的边会标记工程有效性不足。它经过解析高斯模糊和已知弯曲边自检，但不声称获ISO12233实验室认证；正式比赛可用Imatest/SFRmat作交叉基准。
运行自身检查：

    python image_quality.py --self-test --output self_test.json

不要用手机翻拍显示器的照片评价板端像素直线度或MTF；手机镜头、摩尔纹、显示器缩放/降噪都会进入结果。HDMI屏幕的真实清晰度还需要逐像素或标准采集设备验收。
